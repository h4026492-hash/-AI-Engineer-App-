Privacy and accuracy: This panel appears only when the app is explicitly enabled in development and opened through localhost. The file is processed by this local server in memory; the app does not save it, add it to the search index, or send it to a language model. Do not enable this on a public server or upload real patient records to this prototype. OCR can misread medication names, dates, digits, units, and decimal points. Check every character against the original and ask a qualified health professional about personal results.
